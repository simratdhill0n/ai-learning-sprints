# AI Learning Sprints

Hands-on implementation of every major AI domain from scratch.

Each sprint follows the same methodology:
1. Understand the math
2. Implement from scratch — no black box libraries
3. Break it intentionally
4. Scale with proper tools
5. Document findings clearly
